# Evals

This directory contains lightweight seed eval cases for Tellus model routing, safety posture, and
response shape. These are not a full quality benchmark yet.

Use these cases to validate:

- Developer-agent output shape.
- General assistant product grounding.
- Compliance safety boundaries.
- Safety flag behavior for risky requests.

Future eval work should add scored criteria, expected refusal behavior, tenant-specific retrieval
tests, and regression reporting.
